Papers runs these open models and libraries on your iPhone:

== llama.cpp (ggml-org/llama.cpp) ==
MIT License. Copyright (c) 2023-2026 The ggml authors.
Runs the summary model.

== Qwen3.5 (Qwen team, Alibaba Cloud) ==
Apache License 2.0. Downloaded as a GGUF from Hugging Face (unsloth/Qwen3.5-2B-GGUF by default).
Reads the paper and writes the summary.

== sherpa-onnx (k2-fsa/sherpa-onnx) ==
Apache License 2.0. Copyright (c) Xiaomi Corporation and the k2-fsa authors.
Runs the voice model with ONNX Runtime (MIT License, Microsoft).

== Kokoro-82M v1.0 (hexgrad/Kokoro-82M) ==
Apache License 2.0. Converted for sherpa-onnx (kokoro-multi-lang-v1_0).
Reads the summary out loud.

== misaki (hexgrad/misaki) ==
Apache License 2.0. The English pronunciation lexicon (lexicon-us-en.txt) is built from misaki's
us_gold and us_silver dictionaries.
