HOW TO MAKE AN AIRCRAFT FOR SKYLARK

Every aircraft is one small text file ending in .json. To add your own:

1. In the Files app go to On My iPhone > Skylark.
2. Copy a file from the Examples folder into the Aircraft folder.
3. Rename it, open it in any text editor, and change the "id" to something new.
   (Keep a built-in id instead and your file replaces that aircraft.)
4. Change whatever you like, save, then in the game open Hangar and tap Reload aircraft.

If the file has a mistake, the Hangar tells you what and where.


THE SETTINGS

"id"           A short name nothing else uses, like "my-glider".
"name"         What the Hangar calls it.
"type"         How it flies:
                 "plane"       hold to climb, let go to dive
                 "helicopter"  hold to lift, let go to sink; it floats and drifts
"description"  One line for the Hangar. Optional.
"price"        Stars needed to unlock it. 0 or left out means free.
"level"        true keeps it flat instead of tilting as it climbs. Optional.
"trail"        Colour of the puffs it leaves behind. Leave it out for none.

"stats"        All optional.
  "speed"      How fast it flies forward. 80 to 320; 170 is normal.
               Faster means more distance, and less time to react.
  "climb"      How fast it gains height. 0.4 to 2; 1 is normal.
  "agility"    How quickly it answers your finger. 0.4 to 2.5; 1 is normal.
  "magnet"     Pulls stars in from this far away. 0 to 120; 0 is none.

"hitbox"       The invisible box that crashes into things: "width" and "height".
               Smaller is more forgiving. Leave it out and the game works one out.


DRAWING IT: "parts"

An aircraft is drawn from a list of coloured shapes, first one at the back.

Measure from the middle of the aircraft: x goes forward (the nose points right),
y goes up. A normal aircraft is about 90 long and 30 tall, so the nose is near
x 45 and the tail near x -45. The whole sky is 400 tall.

Every part has:
  "shape"      "ellipse", "rect" or "polygon"
  "color"      like "#E94F37". Add two more digits for see-through: "#55555599".
  "outline"    a colour for a thin line round it. Optional.
  "rotation"   turns it, in degrees, anticlockwise. Optional.
  "animation"  optional:
                 "propeller"  flickers tall and thin, like a propeller seen from the side
                 "rotor"      flickers wide and narrow, like helicopter blades
                 "spin"       turns round and round
                 "blink"      fades in and out

An ellipse or rect also needs:
  "x", "y"            where its middle is
  "width", "height"   how big it is
  "radius"            rounded corners, for a rect. Optional.

A polygon needs:
  "points"     a list of corners, each [x, y], at least three
  "smooth"     true turns the corners into curves. Optional.


A TINY EXAMPLE

{
  "id": "paper-dart",
  "name": "Paper Dart",
  "type": "plane",
  "stats": { "speed": 200, "climb": 1.2, "agility": 1.3 },
  "parts": [
    { "shape": "polygon", "color": "#FFFFFF", "outline": "#8D99AE",
      "points": [[-45, 8], [45, 0], [-45, -4], [-35, 2]] },
    { "shape": "polygon", "color": "#DDE3EA",
      "points": [[-45, -4], [45, 0], [-30, -12]] }
  ]
}
